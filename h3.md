# MiniMax H3

"A lot of animation styles". Support merged to Comfy official.

- Model flavors: fl2va and ref2va (multiple references, at least 3, possibly more) "both models do both tasks actually, just more finetuned for their specialties"
- Workflow flavors: i2v, r2v, t2v
- Pruning is removing unnecessary weights, seems like 13B out of 33B have been pruned out, "from what I tested pruned is completely fine, just bit different outputs"
- We have a sort of an edit mode similar to Bernini
- Kijai-style colored bodies understdood natively - via a reference video
- there are reference workflows shipped with Comfy
- video VAE is 5Gb "innately tiled, it uses very little memory ... tiled VAE ... does nothing on this model"
